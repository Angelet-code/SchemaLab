# SchemaLab

**Map the signal. Verify the build.**

SchemaLab is a visual workspace for understanding electronic schematics, mapping functional blocks, documenting components, and tracking a real build or rebuild.

This repository currently contains the Cornford Hurricane / Chillidoggy amplifier project as the first working case study.

## Web app

The static web app lives in:

- `AppWeb/index.html`

GitHub Pages is configured through GitHub Actions to publish the `AppWeb/` directory.

## Current focus

- Interactive schematic view.
- Block-based circuit exploration.
- Component list filtered by circuit section.
- Reconstruction progress tracking.
- Technical documentation for safe real-world rebuild work.
